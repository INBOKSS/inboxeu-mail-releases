INBOX.EU Mail brings your email accounts, attachments and unfinished messages into
one desktop workspace. Use a unified view or work with each mailbox separately,
with a local mail cache and direct connections to your email provider.

## Download

- **Windows 10/11 x64** — [Microsoft Store](https://apps.microsoft.com/detail/9MXZ1TBVHRK6).
- **macOS 13 Ventura or newer, Apple Silicon** — signed and Apple-notarized
  [DMG](https://github.com/INBOKSS/inboxeu-mail-releases/releases).
- **Linux x64** — [AppImage and DEB](https://github.com/INBOKSS/inboxeu-mail-releases/releases).
  AppImage requires FUSE 2; DEB is for compatible Debian/Ubuntu systems.

The links show the currently published versions. Microsoft Store and direct-download
releases can become available at different times. Production packages offer
INBOX.EU and Other IMAP/SMTP accounts, with INBOX.EU selected by default. A compatible
account with secure IMAP/SMTP access is required. Gmail and Microsoft account
sign-in are not available in these releases.

## Highlights

- **Keep conversations moving.** Minimize several new messages, replies or forwards
  to a bottom dock while browsing folders or switching accounts. Each keeps its
  own sending account, text and attachments. Normal Quit/restart saves unfinished
  messages and files to each account's Drafts; a save failure keeps the app open.
- **Write with context.** Rich text, editable tables, inline pictures, supported
  Word/Excel paste, spelling, per-account signatures and drag-and-drop attachments.
  Supported native Excel picture recovery is Windows-only.
- **Catch the small mistakes.** A forgotten-attachment reminder and seven-second
  Undo Send, with Send now when you are ready.
- **Find the file.** Browse attachments across accounts in Files, filter by type
  and group by sender. Preview supported images, PDF, Word, Excel and text in
  the app. Select and copy PDF text when the file contains a text layer.
- **Inspect electronic documents.** Supported signed PDFs and EDOC/ASiC containers
  offer signer information, verification details and separate qualification
  results. Supported formats and signature profiles have limits; this is document
  inspection rather than a signing service.
- **Organize your mail.** Search downloaded messages, manage folders, filter mail,
  mark important messages and use named colored labels on INBOX.EU accounts.
- **Keep the everyday tools close.** Print or save messages as PDF, export .eml,
  inspect source and open email links in the composer. Calendar event details
  are available for every account; responses and calendar links are INBOX.EU-only.
- **Make space to read.** Resizable panes, compact or comfortable rows, light/dark
  themes, keyboard navigation and layouts remembered for your screen setup.

## Updates

Supported release builds check for newer published packages and offer
Settings > About > Check for updates. Store builds open Microsoft Store. Other
packages download and verify their matching installer: a Mac DMG opens for dragging
to Applications, a DEB opens in the package installer, and an AppImage replaces
itself and restarts. Windows updates are also managed by Microsoft Store.

This repository hosts public downloads, screenshots and the verified
`updates.json` catalog. It does not contain the source checkout or private
build credentials. Versions are advertised separately for each platform and
package format, only after publication checks.

## Privacy and support

Downloaded mail, search data and settings are cached on your device. Messages,
drafts and mail actions synchronize with your provider. Saved credentials use
operating-system secure storage; the client includes no analytics or third-party
tracking SDKs. External images in received mail can still contact their hosts.
